Connect the dashboard

One-time setup. The token stays in this browser only and is sent only to GitHub.

  1. Open GitHub → New fine-grained token.
  2. Name it outreach-dashboard, expiration 1 year or longer. Repository access: Only select repositories → outreach-emailer.
  3. Permissions → Repository: Contents: Read-only and Actions: Read and write. Generate token.
  4. Paste it below.
